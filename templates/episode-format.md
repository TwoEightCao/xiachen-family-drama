# 单集剧本标准排版

> **出处**：改编自 [`short-drama-factory`](https://github.com/lixiaoxiao9888-create/short-drama-factory)（MIT，© 2026 lixiaoxiao9888-create「老李」）的 `templates/episode-format.md`。改写范围：保留三档排版骨架；新增必填 `【档位】` 字段并对齐断章五字段格式。完整来源披露见 `NOTICE.md`。

> 交付格式模板。写完必须跑 `python3 "<SKILL>/scripts/validate_episode.py" <文件>` 机检（FAIL 必须修，`<SKILL>` = skill 安装目录），再过 `SKILL.md` §四 Step 5 的人工自检清单；断章格式以 `references/06-hook-cliffhanger.md` §六 为准。

**先定档再动笔**（三选一，规格见 `references/03-audience-paywall.md` §四）：

| 档位 | 时长 | 正文体量（实拍 / 漫剧） | 场景 | 单集拍数 | 对白行 |
|---|---|---|---|---|---|
| 标准档（默认） | 90～120 秒 | 350～500 / 260～400 | ≤2 | 1 拍 | ≥4 |
| 长档 | 165～195 秒 | 650～850 / 520～680 | ≤3 | 2 拍 + 中段小钩 | ≥8 |
| 漫剧档 | 60～90 秒 | 260～400 | ≤2 | 1 拍 | ≥4 |

## 二、 长档模板（约 3 分钟）

```text
第【XX】集：【集名 / 本集小账标签】（长档·约3分钟）
【档位】：长档（165～195 秒）    ← 必填；机检靠它分档，缺失报 E1
【所属阶段】：第X幕・（第 X/40 集 ｜ 单元A ｜ 往返第 N 回合・证据档X/反驳档X）
【黄金前3秒钩子】：五母型之一【母型名】—— 一句话画面
【情绪流变】：憋屈 ➔ 起疑 ➔ 顶回去 ➔ 加压 ➔ 绝命断章
【本集时长】：__ 秒（约 __ 字）
【本集结构】：双回合（回合A ____ ➔ 回合B ____）
   时间骨架：钩 0~8s / 回合A 8~80s / 中段小钩 ≈90s / 回合B 95~170s / 断章 170~195s
【本集小账】：本集要兑现的那一笔公道 = ____

[场景 1]：内景/外景・地点・日/夜        ← 全集 ≤3 个
[人物]：姓名（状态标签）、姓名（状态标签）

△ 特写：钩子——直接切入冲突顶点，禁铺垫。
角色名（神态短语）：
"台词。"        ← 回合A：施压 ➔ 反驳；反驳必须带代价或新信息；全集对白行 ≥8

【本集中段小钩】：≈90 秒处的新信息 / 新威胁 / 反转半步，只抬价不爆点。

[场景 2]：内景/外景・地点・日/夜        ← 第 2/3 场必须是升级场
△ 中景：回合B —— 升级施压（新物证 / 新代价 / 新人证）。
角色名（神态短语）：
"台词。"        ← 升级反驳 / 翻盘未遂，禁复读回合A 话术
△ 中景：情绪顶点落地 + 静默反应镜头。

【本集断章卡点】
公式：公式 X【公式名】
停格画面：……
停格台词：「……」
观众问句：……
黑屏：（黑屏：下滑解锁第 XX 集）
```

**长档三条追加铁律：**
1. 一集两拍（回合A / 回合B），回合B 的施压与反驳各升一档；
2. ≈90 秒处必设【本集中段小钩】，只抬价不爆点；
3. 每 30 秒一个新增量；场景 ≤3 且第 2/3 场必须是升级场。

## 三、 写前写后规程

```text
写前：读台账（四类账全读）→ 读分集规划 → 读回合表定位本集档位与拍数
写后：更新台账（伏笔/人物关系/道具/规矩）→ 跑机检脚本 → 过人工自检清单 → 过合规自检清单
```

**四条排版禁令：**
1. 不写抽象心理词（「她很伤心」→ 写成「她用围裙角擦了三下眼睛」）；
2. 不写镜头术语堆砌（「推拉摇移跟」只保留必要的，且以可拍摄为准）；
3. 不用旁白交代人物关系（旁白只能承接情绪，不能讲设定）；
4. 不用「（画外音）」「（内心 OS）」替代本可以演出来的动作。
