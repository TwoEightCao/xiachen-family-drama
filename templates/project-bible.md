# 立项单与项目圣经模板

> `/立项` 产出的四件套模板 + `/全剧大纲` 的单元链/回合表/付费墙模板。所有字段都要填满，空缺处标注「待定」不可留白。
>
> **本文件是「立项单 / 人物表 / 四幕骨架」的唯一权威模板**（`references/03-audience-paywall.md` §五 已改为指向本文件）。集数档位只认 `03-audience-paywall.md` §四。

---

## 一、 立项单四件套（`/立项` 必产）

```text
【剧名】（暂定）：
【主赛道】：F_ ___            【辅赛道】：F_ ___ / 无（禁止组合见 01-genre-map §三）
【情绪契约】：让不认我的人当众认账 —— 具体兑现物=____
【执念一句话】：____（谁，坚决不认/不服什么）
【目标集数 / 档位】：标准档 60/80/100 集 或 长档 30/40/50 集 或 漫剧档 60/80/100 集（漫剧长档正文 520～680）
【目标平台】：红果 / 抖音 / 快手 / 小程序（判据见 03-audience-paywall.md §五）
【结局认账形式】：____（族亲聚会 / 法庭 / 协议签字 / 族谱补名）
【一句话故事】：____（≤50 字，念给 60 岁的人能听懂）
```

### 1.1 四幕骨架（同属 `/立项` 必产，格式固定为每幕一句话走向）

```text
【一幕·入局压迫】（第 __～__ 集）：____（把主角按在最低处的那件事 + 首轮小反击）
【二幕·升级纠缠】（第 __～__ 集）：____（单元循环主体区：换矛盾不换情绪）
【三幕·风暴危机】（第 __～__ 集）：____（终极反派反扑 + 底牌失效 + 最大信任危机）
【四幕·决战认账】（第 __～__ 集）：____（底牌全开 + 当众认账的具体场合）
```
集区间必须落在 `references/03-audience-paywall.md` §三 的对应格子内。

## 六、 交付目录约定

**项目目录确定规则**：① 用户指定了路径 → 用用户的；② 用户未指定 → 在当前工作目录下建 `{剧名}-{赛道编号}-{档位}/`（剧名取立项单暂定名，去掉 `/ \ : * ? " < > |` 等特殊符号）；③ 同名目录已存在 → 直接复用并在其中续写，不新建、不加后缀。

```text
{项目目录}/
├── 立项单.md
├── 人物圣经.md
├── 全剧大纲.md          # 单元链 + 回合表 + 付费墙
├── 分集规划.md
├── 台账.md              # 唯一事实源（空表从 templates/ledger.md 复制，别手搓格式）
├── episodes/
│   ├── ep001.md
│   └── ep002.md
└── 合规报告.md          # 如生成
```
