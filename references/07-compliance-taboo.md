## 一、 平台一票否决类（碰一条即废稿，不可商量）

1. **教唆或美化遗弃老人**：不能出现「老人被扔在养老院不管」被当作合理解决方案，也不能让主角用「断绝关系」作为最终胜利。赡养是法定义务，剧中必须落地。
2. **渲染子女互害的暴力手段**：下毒、纵火、伪造死亡等手段不得给出可操作细节，也不能以「解气」呈现而不受惩罚。
3. **封建迷信与改命导向**：算卦定生死、下蛊、托梦指路不可作为剧情推力；民俗元素可作氛围（上香、祭祖），不可作因果。
4. **涉政涉军涉警违规**：不得丑化公职人员形象；不得违规使用真实国家机关名称（用「区法院」「街道办」「派出所」这类泛称）。
5. **低俗与不良婚恋观**：不得宣扬重婚、出轨合法化、买卖婚姻、物化女性（尤其「花钱买个媳妇」类桥段）。
6. **极度血腥暴力**：不得出现断肢、开膛破肚、直观殴打特写；冲突以「推搡、摔门、掀桌、昏倒、送医」等写意手法呈现。
7. **骗婚/诈骗的可操作细节**：伪造证件、具体骗术流程不得细化教学；呈现结果与法律后果即可。

## 二、 家庭伦理专属雷区（本赛道特有，最容易翻车的地方）

| 雷区 | 症状 | 修法 |
|---|---|---|
| **把老人写成只会哭的工具** | 全剧被动挨打，无任何主动性 | 每 10 集至少动用一次「藏着的底牌」（见 `04-character-bible.md`） |
| **把子女写成纯恶** | 反派一坏到底，无动机 | 四层反派中第 2 层必须有可理解的动机（「我也难」是处境，不是台词） |
| **靠暴力泄愤收尾** | 结局是「打了恶媳一顿」 | 结局必须落在当众认账 + 秩序修复（道歉/认亲/赡养落实/法律制裁） |
| **宣扬「忍就对了」** | 主角一味忍让，结局无兑现 | 憋屈与释放比 3:1，单元闭环必须兑现 |
| **重男轻女被当作正向价值** | 「家产本来就该给儿子」被当作正当理由 | 可作**反派的错误依据**出现，但结局必须被否定（法律或族亲当众纠正） |
| **地域/职业抹黑** | 把某省、某职业（保姆/护工/月嫂）整体写成坏人 | 恶行归个人，不归群体；同群体里必须有正面的公道见证人 |
| **未成年子女卷入恶行** | 让孩子参与陷害、撒谎构陷 | 小辈只能作反转支点（童言无忌揭真相），不能作施害者 |
| **自杀/自残作为要挟** | 「你不养我就死给你看」被写成有效手段 | 可出现情绪崩溃，但不能作为解决问题的路径，且必须有人介入干预 |
| **家族私刑** | 族亲围攻、游街、私刑逼供 | 私刑不得作为正义实现方式；要落到村委调解、法院判决 |

## 三、 敏感词与替换转译库

| 禁用 / 高危表述 | 合规替换 |
|---|---|
| 「杀了你 / 要你的命」 | `让你付出代价 / 这事没完 / 我跟你没完` |
| 「老不死的 / 早点死了算了」 | `你就别管了 / 你歇着吧`（刻薄但不出格，靠语气和动作补） |
| 「把你送精神病院」 | `让你去疗养院住一阵` |
| 「断子绝孙 / 绝户」 | `这一支就到你为止了` |
| 「黑社会 / 找人打断你的腿」 | `找人来评评理 / 这事我找人说道说道` |
| 「伪造遗嘱最高招」 | `把遗嘱改了 / 字不是我签的`（不写操作细节） |
| 「上访 / 告到中央」 | `去区里反映 / 走法律程序` |
| 「卖房子搬走不管了」 | `搬出去住 / 这房子我住不下去` |
| 「私了 / 拿钱封口」 | `把话说清楚再谈钱` |
| 「全村人都知道你家那点事」 | `这楼里谁不知道` |

**转译原则：** 情绪强度不能降，只降表达烈度——用一个更家常、更含蓄但同样能噎住人的说法替换，而不是把台词改软。

## 四、 伦理呈现规范（三条正向要求）

1. **赡养必须落地**：无论反派多恶，结局必须给出可执行的赡养安排（协议签字、轮流表、费用分摊），不能模糊收尾。
2. **公道要有程序感**：主角的胜利越依赖「程序」（笔迹鉴定、村委会调解、法院判决、原始凭证），越有说服力，也越安全。私力救济只能作过程。
3. **恶行必有代价**：每个反派的结局处置要与他的行为匹配（认账 / 认账+补位 / 自食其果 / 认罪+规矩重立），不能不了了之。

## 五、 合规自检清单（写完逐条过）

```text
□ 一票否决七类，一条不沾
□ 结局是当众认账 + 秩序修复，没有暴力泄愤
□ 主角每 10 集至少动用一次底牌，不是纯受害者
□ 第 2 层反派有可理解的动机，不是纯恶
□ 恶行归个人不归地域/职业，同群体有正面见证人
□ 未成年人没有参与施害
□ 没有教唆遗弃、没有把「断绝关系」当胜利
□ 敏感词已按 §三 转译，情绪强度未降
□ 赡养/继承/拆迁相关情节没有法律常识错误（继承顺序、赡养义务、拆迁补偿归属）
□ 涉及鉴定、诉讼、调解的情节不给出可操作违法细节
```
