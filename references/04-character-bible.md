## 一、 单角色四件套（缺一不得建档）

| 件 | 要求 | 本赛道反例 |
|---|---|---|
| 1. 动机 | 一句话、可被镜头拍到：她要在哪件事上被谁认账 | 「想让家里和睦」（不可拍，也不是执念） |
| 2. 秘密 | 最怕被谁知道什么；决定其在往返回合里的反驳底线与代价上限 | 无秘密＝无拉扯资本，第 20 集后必疲劳 |
| 3. 弧光 | 打法随单元升级，不是性格变化：被动自证 → 主动设局 → 掌控规矩；标清在哪单元哪回合变 | 80 集原地当受害者 |
| 4. 语言指纹 | 遮名字能认出是谁：口头禅／句长／称谓习惯／市井俗语密度 | 全家一口播音腔 |

**四件套与契约的挂靠点**：动机＝本单元执念的持有者；秘密＝证据六档与反驳六档的燃料；弧光＝三缝合一的「主角弧光跟单元走」；语言指纹＝`05-voice-dialogue.md` 的声口库入口。

```text
【姓名】：______（性别／年龄／身份明面／身份暗面）
【动机】：______（要谁，在哪件事上，当众认什么账）
【秘密】：______（第__集被__利用；泄露后返回合走向如何改）
【弧光】：被动自证（单元__）→ 主动设局（单元__）→ 掌控规矩（单元__）
【语言指纹】：口头禅「____」／句长__字／对__称「__」／俗语占比__
【底牌】：一笔钱□ 一门手艺□ 一份证据□ 一个还认她的人□ 一段没人知道的过去□
【功能位】：____（主角／第__层反派／配角功能位）
【出场】：第__集 ｜【状态机】：见台账「人物账」
```

## 二、 老年主角设计（本赛道核心）

**硬规矩 1：不许把老人写成纯受害者。** 主角必须在第 1 集就带着「藏着的底牌」入场，且底牌按集数定额动用。没有底牌的老人只能憋屈 10 集，第 11 集观众就换台。

### 2.1 主角三种起点原型

| 原型 | 开场姿态 | 前 10 集行为 | 观众第一情绪 | 适用赛道 | 塌陷风险 |
|---|---|---|---|---|---|
| 忍让型 | 主动退半步：「一家人，我不计较」 | 忍、记账、不还嘴 | 心疼 + 憋屈 | F1 婆媳清算／F5 养老困境／F6 保姆护工 | 忍过头，观众骂主角窝囊 |
| 硬气型 | 当场顶回去：「这话你今天说清楚」 | 顶、立规矩、得罪人 | 服气 + 期待 | F4 家产争夺／F8 拆迁暴富与亲戚 | 太强，反派压不住，回合失衡 |
| 糊涂型 | 真糊涂或装糊涂：「我记不清了」 | 被绕、被代签、被搬走东西 | 着急 + 好笑 + 心疼 | F7 黄昏恋骗婚／F3 寻亲认子 | 糊涂太久，观众觉得主角蠢 |

**选择规则**：一剧只选一个原型做**起点**；第 20～30 集允许向「硬气」迁移一次（这就是弧光第一跳），但**不允许**把忍让型写成从头到尾不还手。

### 2.2 三种原型的「藏着的底牌」清单

底牌＝契约硬规矩 1 的五类。**开局至少持 2 张，全剧累计不超过 3 张**；每张必须登记进台账「伏笔账」。

| 底牌 | 忍让型 | 硬气型 | 糊涂型 |
|---|---|---|---|
| 一笔钱 | 存折／养老钱，被子女惦记但没交出去 | 私房钱／卖粮款，随时能拍桌上 | 拆迁卡／补偿款，被代管、去向不明 |
| 一门手艺 | 裁缝／做饭／接生／修鞋，能自己挣饭吃 | 打算盘／开车／老本行技术，能翻盘生计 | 种地／腌菜／看小孩，被全家当免费劳力 |
| 一份证据 | 一本记账本、一串转账记录 | 录音／收据／老分家单、老房契 | 一沓单据，自己都忘了放过哪 |
| 一个还认她的人 | 老邻居、老同事、娘家侄女 | 老战友、老厂长、退休法官 | 亲家母、保姆、老同学 |
| 一段没人知道的过去 | 年轻时的手艺或功劳，从不提 | 当年替全家扛过的事，被抹掉了 | 一段旧情／旧身份，被压了一辈子 |

**三原型差异口诀**：忍让型的底牌**不能早亮**（前 20 集只露边角）；硬气型的底牌**可以早亮一张**（前 10 集先镇场）；糊涂型的底牌**必须别人提醒才想起来**（唤醒＝一个转折点）。

### 2.3 主角弧光三档（与单元 A/B/C 对齐）

| 档 | 单元 | 打法 | 主角动作 | 底牌使用额度 | 单元收口 |
|---|---|---|---|---|---|
| 被动自证 | 单元 A | 别人泼脏水，她自证一件事 | 举证、对质、被人抢白 | 每 10 集至少动 1 次，且只动边角 | 洗清一件事，但代价升一档 |
| 主动设局 | 单元 B | 她自己摆局让对方钻 | 借力、留证、逼对手先出手 | 每 10 集至少动 1 次，可动主牌 | 对手换层不换欲，进入下一层 |
| 掌控规矩 | 单元 C | 她用规矩反制定规矩的人 | 重立家规／重新分家／当众定公道 | 收尾一次性全亮 | 当众认账 + 伦理秩序修复 |

**硬性配额**：**主角每 10 集至少动用一次底牌**；连续 10 集不用底牌＝该单元不合格，返工。每次用牌必须留下新代价（反驳成本升一档），不许白拿。

### 2.4 「主角人设卡」完整填写示例（F1 婆媳清算·女·60 岁上下）

```text
【姓名】：周桂兰（女，61，明：退休纺织厂女工／暗：当年厂里唯一会做精细成衣的人）
【动机】：要儿媳刘美娟在满月宴上当众认一句——「这三年，是妈伺候的我」
【秘密】：三年前偷偷卖了自己的老房给儿子凑首付（第 34 集被恶媳反用来骂她「没资格住这」）
【弧光】：被动自证（单元A，1～25集：被嫌土、被赶厨房吃饭，只敢说「妈不挑」）
        → 主动设局（单元B，26～52集：接下对门邻居的改衣活，让全家看见她能挣钱，逼小两口先开口）
        → 掌控规矩（单元C，53～80集：当众念三年记账本，重立「谁住谁的房、谁认谁的账」的家规）
【语言指纹】：口头禅「我不挑」；句长 6～12 字；对儿子称「崽」，对儿媳从「美娟」降到「刘美娟」再回到「美娟」；俗语占比高（「人心都是肉长的」）
【底牌】：开局持 2 张——一门手艺☑（裁缝，第 28 集起接活挣钱）／一份证据☑（三年记账本）
        ／第 38 集补第 3 张：一笔钱☑（老房尾款 8 万，一直没交）
        ／一个还认她的人□（第 30 集引入老同事，只作人证不算底牌）／一段没人知道的过去□
【功能位】：主角 ｜【出场】：第 1 集 ｜【状态机】：见台账「人物账」
【反派层级对照】：恶媳刘美娟（第1层）／儿子周建军（第2层，可理解动机层）／小姑（第3层）／
        当年偏心分家的老规矩（第4层）
```

## 三、 四层反派体系（本赛道改名版）

**硬规矩 2：不许子女反派一坏到底。** 每部剧必须**指定一层为「可理解动机层」**（默认第 2 层），该层反派的恶要有能说出口的难处，结局的认账才有重量。

反派共同约束：**有身份、有脸面、有软肋**；恶只有一种逻辑（贪／势／妒／怕丢人，选一），**换人不换欲**（三缝合一）。

### 第 1 层 恶媳／恶婿（前台）

| 项 | 内容 |
|---|---|
| 功能 | 贴身施压，制造日常摩擦，把家变小战场；每场戏负责推进「证据升一档」 |
| 施压手段 | 嫌土、立家规、查账、断生活费、当面数落、拿孩子当筹码 |
| 软肋 | 怕婆婆的钱不进自己口袋；怕丈夫知道她背地里的账；怕外面丢脸面 |
| 结局处置 | **认账**（当众认下她占的那份便宜，不一定要道歉到底） |
| 台词样例 | 「妈，你那套老规矩，在我们家不适用。」 |

### 第 2 层 白眼狼子女（利益既得者）

| 项 | 内容 |
|---|---|
| 功能 | **默认可理解动机层**：利益既得者，把「我也难」当挡箭牌；制造主角最痛的那一刀——亲生的不认账 |
| 施压手段 | 装穷、推给配偶当枪、拿孩子学费当理由、签字代管、装聋作哑不表态 |
| 软肋 | 怕妻子／丈夫闹；怕单位、亲戚知道真相；怕自己在孩子面前没了形象 |
| 结局处置 | **认账 + 补位**（把钱和赡养补上，修复伦理秩序；不写断绝关系收尾） |
| 台词样例 | 「妈，我也难，你就不能体谅体谅我？」 |

### 第 3 层 伪善亲戚／乡邻（舆论施压者）

| 项 | 内容 |
|---|---|
| 功能 | 和事佬外壳下的舆论施压者：不直接抢，但让主角「没法开口」；负责把私事变成公开话题 |
| 施压手段 | 劝忍、传话、家族微信群带节奏、村口点评、拿「面子」绑架主角 |
| 软肋 | 怕自家丑事被翻出来；怕分不到好处；怕被人说不公道 |
| 结局处置 | **自食其果**（自己那点事被当众说破，舆论场反转，从此不敢再来劝忍） |
| 台词样例 | 「都是一家人，何必闹到外人跟前？忍忍就过去了。」 |

### 第 4 层 幕后真凶／规矩本身

| 项 | 内容 |
|---|---|
| 功能 | 拿走最大利益的人，或「偏心」这条家规的制定者；前三层只是执行者 |
| 施压手段 | 不下场，只定规矩：老分家单、房本名字、口头承诺、乡约「长子继承」「闺女不分」 |
| 软肋 | 规矩要站得住就得有人信；一旦被当众证明当年偏了，脸面与利益同时塌 |
| 结局处置 | **认罪／认错 + 规矩被重立**（改房本、重分家、当众认当年偏心） |
| 台词样例 | 「这规矩是老辈子传下来的，不是我定的——要怪，怪这规矩。」 |

**层级过渡规则**：第 1 层退场必须带出第 2 层的一句「你以为赢了？」；第 2 层倒台必须露一次第 4 层的规矩。**禁止**把第 4 层写成天降人物——前 20 集至少埋 3 处可回溯细节。

## 四、 配角功能位清单

| 功能位 | 常用身份 | 功能 | 1 个使用要点 |
|---|---|---|---|
| 公道见证人 | 老邻居／老同事／退休法官 | 在关键回合替主角「定性」——不替她出手，替她作证 | 每单元出场 ≤3 次，只说事实不下判词，判词留给主角自己说 |
| 利益缓冲垫 | 老实巴交的中间子女 | 双轨：递错证据造成误会，或关键时刻给出真话 | 每单元只给 1 次「站队机会」，逼他在两份利益里选一次 |
| 反转支点 | 被忽略的小辈／保姆 | 手里有最关键那份人证或录像，自己却存在感极低 | 前 20 集至少 2 次在场但不说话，反转才不突兀 |
| 舆论场（**场所，非角色，不占具名名额**） | 家族微信群／村口／居委会 | 把私事变公开，让「当众认账」有舞台 | 每次舆论转向必须由主角当众出示证据驱动，不许靠路人自发 |

## 五、 全员名册模板

配额：**具名角色总数 ≤12** = 主角 1 ＋ 四层反派 4（第 1～4 层各 1 名）＋ 配角功能位 3 名（公道见证人／利益缓冲垫／反转支点）＋ **情感锚点 1～2 名**（定义：与主角有私人情感联结、**不承担证据升档职能**的软性角色，如老伴、老姐妹、孙辈）＋ 机动 1～2 名。第 13 张脸观众记不住，降群演。

> **「舆论场」不是角色，是场所**（家族微信群／村口／居委会，见 §四 表），**不占具名名额**，在名册备注里标注即可。

```text
| 姓名 | 身份 | 与主角关系 | 动机（一句话，可拍） | 秘密 | 语言指纹 | 所属反派层级 | 可理解动机层 |
|---|---|---|---|---|---|---|---|
|      |      |            |                      |      |          | 第__层／无    | 是／否        |
|      |      |            |                      |      |          |              |              |
|      |      |            |                      |      |          |              |              |

备注：本剧可理解动机层＝第__层（姓名______），其难处一句话是：____________
```

建档规程：先建圣经 → 后出大纲；每个具名角色必须携带「证据升档职能」（TA 出场＝往证据阶梯推一档），不推档的角色不立。

## 六、 人物一致性校验清单

- [ ] 1. 每个反派的施压手段，都能一句话追溯到他自己的软肋（追不到＝纯恶，返工）。
- [ ] 2. 主角每 10 集至少动用一次底牌；连续 10 集未用＝该单元不合格。
- [ ] 3. 遮住名字读台词，能否认出是谁在说（语言指纹生效）；全员播音腔＝返工。
- [ ] 4. 每个具名角色是否至少推动过一次「证据升一档」；一次都没有的降群演或删。
- [ ] 5. 每层反派的结局处置方式，是否与他的软肋对上（认账／认罪／自食其果），禁止统一写「被抓走」。
- [ ] 6. 语言指纹是否全程一致（含称谓变化，如「美娟」→「刘美娟」→「美娟」的节点是否登记在台账）。
- [ ] 7. 秘密被揭穿之后，是否改变了往返回合的走向（没改变＝这个秘密没用，删或改）。
- [ ] 8. 具名角色总数 ≤12；「可理解动机层」是否已明确指定并写入名册备注。

**致命问题**（出现任一即整份人设退回）：

- ❌ 主角是纯受害者，全剧没有底牌，或底牌只在最后一集才亮。
- ❌ 四层反派层层纯恶，「我也难」只是台词不是处境，第 2 层的认账轻飘飘。
- ❌ 结局落在暴力泄愤（打人、砸门、以死相逼当爽点兑现物）。
- ❌ 四层反派对不上号：第 1 层直接指挥第 4 层，层级过渡缺「你以为赢了？」这类衔接。
