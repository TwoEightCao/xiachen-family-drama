## 一、 本赛道声口总纲

**1.1 为什么不能用播音腔**

| 播音腔特征 | 下沉观众的真实反应 | 后果 |
|---|---|---|
| 字正腔圆、气口均匀、句尾上扬 | 「这是电视台念稿的，不是我家的人」 | 3 秒内划走 |
| 成语、书面语、逻辑连词成套 | 「听不懂，跟我没关系」 | 不进戏，不进情绪契约 |
| 情绪平稳、音量中等 | 「没劲，不吵不闹看啥」 | 黄金前3秒失守 |
| 台词太完整、太有教养 | 「假，谁家吵架这么说话」 | 不付费 |

本赛道观众（45～70 岁、三四线及县域、竖屏手机、免费集看到付费墙掏出几块钱买一口气）**靠耳朵认人**。台词一旦光滑，人物就假，情绪契约就立不住。

**1.2 中老年下沉观众的语言节奏**

| 节奏手段 | 做法 | 例子 |
|---|---|---|
| 短句 | 一句一个意思，句号砸下去，不用逗号连 | 「我伺候你月子。你嫌我土。」 |
| 重复 | 关键词原话重复两三遍，越重复越上头 | 「钱呢？钱呢？我问你钱呢？」 |
| 反问 | 质问句代陈述句，把举证责任甩给对手 | 「我哪点对不起你？」 |
| 起手式 | 开口先垫一句身份或委屈，再进正题 | 「我这辈子…」「我不图别的…」 |
| 嗓门错位 | 该低的时候压到几乎听不见，然后炸一次 | 「（低声）行。（拍桌）你行你上！」 |
| 称呼当武器 | 改口就是翻脸，一句称呼能当断章 | 「妈？你也配叫？」 |

**本赛道核心原则：台词不是说话，是掰扯。** 不是把信息说出来，是把道理一句一句掰开，掰到对方哑口、掰到观众替她出气。写台词先问：这一句是在「讲」还是在「掰」？讲就删，掰就留。

**1.3 执念台词化（对接情绪契约）**：执念是单元内「谁，坚决不认/不服的那件事」。每一句有效台词必须能翻译成执念的一小块——**「谁」不认「什么账」**，翻不出来就是废台词。

```text
【执念台词化公式】我这辈子的（付出）+（被抹掉的证据） → 今天你得（认账动作）
F1 例：我伺候你月子，你嫌我土 → 今天当着你男人的面，把这话说清楚
F2 例：我养你大，你嫌我老 → 今天你当着全村，喊我一声爸
```

## 二、 七类人物的语言指纹

> 用法：写完一集遮住人名通读；出现「分不出谁在说」的句子，按本表重写。

**2.1 忍让型老年女主**

| 特征 | 说明 |
|---|---|
| 起手式软化 | 开口先把自己放低：「我这辈子…」「我不图别的…」「我不怨谁…」 |
| 重复受委屈的关键词 | 一个字重复两三遍，把委屈压实，不给对方插嘴的缝 |
| 把话让在自己身上 | 说出的话全部指向自己，反而让对手没法接 |

```text
我这辈子没求过人，今天就求你一回。
我不图房子，我就问一句话。
我不怨你，我怨我自己眼瞎。
```

**2.2 硬气型老年主角**

| 特征 | 说明 |
|---|---|
| 短命令句 | 不解释、不铺垫，命令直接砸，句尾不留余地 |
| 把死话放最后 | 前句给台阶，末句封路，封完不再说话 |
| 拿规矩压人不拿道德 | 说的是「咱家的规矩」「老理儿」，让对手无处还嘴 |

```text
搬走。现在就搬。
你要叫我一声奶奶，这钱你可以拿走。
规矩就是规矩，我还没老糊涂。
```

> 硬规矩对接：硬气不等于动手。打人只能作过程手段，不能作爽点兑现物；本条主角必须有「藏着的底牌」，台词要把底牌的存在感压住不揭穿。

**2.3 恶媳／恶婿（市井刻薄，反问句主导）**

| 特征 | 说明 |
|---|---|
| 反问句主导 | 三句里两句是反问，答不答都由她说 |
| 当众贬低＋抬高自己 | 把对方钉在「土、脏、穷」上，把自己挂上「我娘家、我花钱」 |
| 贴标签定性 | 一句话把对方钉死成身份标签，不给第二句机会 |

```text
我图你什么？图你这一身土味儿？
谁家老太婆天天来儿子家点卯？
这房子是我娘家添的，你算哪门子主人？
```

**2.4 白眼狼子女（用「我也不容易」当挡箭牌）**

| 特征 | 说明 |
|---|---|
| 挡箭牌先行 | 先喊委屈、再提要求，绝不正面回答质问 |
| 把付出折成价钱 | 把老人一辈子的付出换算成今天的钱、房、床位 |
| 错位反咬 | 被追问时反过来指责老人「不讲理、爱计较」 |

```text
我一个月就挣这么点，我也想孝顺。
你把我养大花了多少？我加倍给你行不行？
别闹了行吗，我这张脸不要了？
```

> 硬规矩对接：本条人物不许一坏到底。每单元至少给一句「可理解的动机」台词（房贷、孩子学费、被媳妇拿话逼住），结局的认账才有重量。

**2.5 伪善亲戚／乡邻（和事佬话术）**

| 特征 | 说明 |
|---|---|
| 「都是一家人」万能开场 | 拿亲情当胶水，把是非问题糊成和气问题 |
| 「有话好好说」「各退一步」 | 不解决冲突，只解决「说冲突的人」 |
| 受害者有罪论 | 末句必落在「你也让一步」，把公道偷换成体面 |

```text
都是一家人，有事坐下来说。
你也别太较真，人老了图个和气。
先吃菜先吃菜，吃完这顿再说这事。
```

**2.6 公道见证人（老邻居／退休干部，讲理不讲情）**

| 特征 | 说明 |
|---|---|
| 不站队先摆事实 | 先给时间、地点、在场人，再给结论 |
| 只认理不认情 | 用规矩、政策、老理儿说话，不劝和 |
| 一锤定音 | 台词短、平、慢，说完就散场，不啰嗦 |

```text
这事我看着呢。
从我这儿论，理不在你这边。
我在村里管了二十年事，这话我敢说。
```

**2.7 小辈／孙辈（反转支点）**

| 特征 | 说明 |
|---|---|
| 童言无忌 | 用孩子天真的重复，把大人藏的事当众说出来 |
| 现代视角 | 用手机、录像、转账记录当讲理工具 |
| 不站队提问 | 一句天真发问，逼全场表态 |

```text
奶奶别哭，我给你擦擦。
我把你刚才说的话录下来了。
姥姥吃的是馒头，我妈给我点的是外卖。
```

## 三、 亲属称谓表（地域差异对照）

> 用法：人物名册里为每个角色锁定一套称谓，全剧不改；称谓就是地域与人物的身份证。

| 关系 | 北方 | 南方 | 县域常见 | 备注 |
|---|---|---|---|---|
| 母亲 | 妈、娘 | 妈、阿妈 | 娘、妈 | 老一辈女性角色「娘」更苦情，都市媳妇「妈」更冷 |
| 祖母 | 奶奶、老奶奶 | 阿婆、婆婆 | 奶奶、婆 | 南方「婆婆」可指祖母，极易与媳妇口中的婆家婆婆撞车 |
| 祖父 | 爷爷、爷 | 阿公 | 爷爷、老爷 | 北方「老爷」另有「地主」义，谨慎 |
| 外祖母／外祖父 | 姥姥、姥爷 | 外婆、外公 | 姥娘、姥姥 | 寻亲认子（F3）最吃这一组，叫错即露馅 |
| 女婿 | 姑爷 | 女婿 | 姑爷、女婿 | 北方「姑爷」带亲近或谄媚味，恶婿场景反讽用 |
| 女婿之父 | 亲家公 | 亲家 | 亲家 | 拆迁暴富与亲戚（F8）谈判戏必用 |
| 伯父 | 大爷、大伯 | 伯伯 | 大爷 | 北方「大爷」可作泛称，指向不准会乱人物关系 |
| 叔父 | 叔、老叔 | 叔叔 | 叔 | 县城「老叔」用于比自己父辈略远者 |
| 兄 | 哥、大哥 | 阿哥 | 哥 | — |
| 弟媳／兄嫂 | 嫂子 | 阿嫂 | 嫂子 | 恶媳（F1）常被叫「嫂子」而非「儿媳妇」，距离感来源 |
| 保姆／护工 | 大姐、阿姨 | 阿姨 | 阿姨、大姐 | 保姆护工（F6）里，改口叫「妈」就是金句支点 |

**称谓错用为什么会毁掉真实感**

| 错法 | 观众为何一眼识破 | 正确做法 |
|---|---|---|
| 北方老人被叫「阿婆」 | 地域标签立刻打架，观众判定「编的」 | 一角色一套称谓，全剧统一 |
| 媳妇当面叫婆婆「婆婆」 | 真实生活中当面叫「妈」；叫「婆婆」是背后称呼 | 当面／背后两套称呼分开写，切换即情绪信号 |
| 姥姥写成奶奶 | 女儿家的孩子不可能叫奶奶，人物关系塌 | 按母亲一侧锁定「姥姥／外婆」 |
| 恶媳叫老人「她」不用称谓 | 缺称呼＝没身份，人物立不住 | 恶媳用「你」「她」+ 标签词，故意省略称谓来施压 |
| 孙辈叫「祖母」 | 书面语，孩子不会说 | 孩子只说「奶奶」「姥姥」，越口语越可信 |

## 六、 去 AI 味七维诊断

> 每写完一集，七个维度各过一遍；任一维度亮红，回炉重写该段，不许「整体感觉还行」放行。

| 维度 | AI 味症状 | 改写动作 |
|---|---|---|
| 1 语言指纹 | 全员一个腔，遮住人名分不出谁在说 | 按第二节七类指纹，给每人各挑 2 条特征落到台词 |
| 2 反向灌输 | 角色对着对手念对方已知道的背景设定 | 删设定，改由物证、称呼、旧事一句带出 |
| 3 攻防回合 | 单方面说教，一人连说三句无人接 | 一句一回合：施压→反驳→再施压；一场戏不许烧完六档 |
| 4 字数限额 | 长复合句、一句塞两个意思 | 拆句，单句 12～18 字，爆发金句 8～12 字 |
| 5 书面语污染 | 成语、连词、敬语、被动句成套 | 换成口语词与断句，删「因此」「然而」「非常」 |
| 6 情绪直给 | 角色把情绪说出来而不做出来 | 情绪转动作或物件，让台词只说一半 |
| 7 复读机 | 同一反驳话术跨回合重复 | 每回合换一个反驳角度，同一话术全剧只用一次 |

**改写前后对照（中老年家庭伦理语境）**

|---|---|---|---|

## 七、 台词硬指标

| 指标 | 标准 | 违反后果 |
|---|---|---|
| 单句常规字数 | 12～18 字 | 出戏、划走 |
| 爆发金句字数 | 8～12 字 | 爽点不炸，付费墙不掏钱 |
| 单句硬上限 | ≤25 字，任何情况下不得突破 | 机检不过，直接回炉 |
| 对白行数下限 | **标准档（90～120 秒）≥4 行；长档（165～195 秒）≥8 行；漫剧档（60～90 秒）≥4 行**。唯一权威：`03-audience-paywall.md` §四（与机检 `SPEC` 同值），本表不得另立数值 | 静场过多，黄金前3秒失守 |
| 禁止复读 | 同一反驳话术不得跨回合重复；同一金句全剧只用一次 | 观众预判，情绪流断档 |
| 起手式强制 | 老年主角每集至少 1 句带起手式（「我这辈子…」「我不图别的…」） | 人物不成立 |
| 称谓一致 | 全剧称谓锁定，当面／背后两套分开 | 真实感崩塌 |
| 回合挂钩 | 单场戏攻防只推进往返回合的一档，不许一场烧完六档 | 单元结构塌 |

```text
【机检口径（与骨架机检思路一致）】
1. 逐行统计中文字符数，超 25 字报错。
2. 抽取全部反驳句做相似度比对，出现重复即报错。
3. 检索辱骂词库，命中第三档直接一票否决。
4. 检索称谓表，同一角色称谓不一致即报错。
```

## 八、 台词自检清单

- [ ] 遮住人名，能否一眼认出每句话是谁说的？
- [ ] 每一句能否翻译成执念的一小块（谁不认什么账）？
- [ ] 黄金前3秒是否见冲突，且冲突含「付出物 + 被否定的动作」？
- [ ] 单句是否 ≤25 字，常规句 12～18 字，爆发金句 8～12 字？
- [ ] 对白行数是否达到本档位下限，有无连续三行以上无对白的静场？
- [ ] 同一反驳话术是否跨回合重复？同一金句是否跨集复读？
- [ ] 是否出现播音腔书面语（因此／然而／非常／综上所述）？
- [ ] 辱骂是否全部落在第一档或已完成转译，有无第三档残留？
- [ ] 亲属称谓是否按地域锁定，当面／背后称呼是否分开？
- [ ] 断章是否把认账动作往后推一步，有无平静收尾？
