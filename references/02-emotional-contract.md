# 情绪契约单元链往返法（本赛道权威）

> **出处**：改编自 [`short-drama-factory`](https://github.com/lixiaoxiao9888-create/short-drama-factory)（MIT，© 2026 lixiaoxiao9888-create「老李」）的 `references/emotion-flow-roundtrip.md`。改写范围：保留情绪契约／单元链／三缝合一／证据六档／反驳六档／攻守转换骨架；每一档实例改写为中老年家庭伦理语境；新增「档 6 归主角打出」规则与集数仲裁。完整来源披露见 `NOTICE.md`。

> ★权威（`/立项` `/全剧大纲` 必读）：本赛道属于**情绪流**，全剧的锚是**情绪契约**（观众每集要续期的那口气），不是钉死的单一矛盾。本文件管两件事：①一个矛盾单元内如何 6 回合高烈度拉扯；②60～100 集如何用 2～4 个单元串成链，情绪不变换战场。**单一矛盾硬拉超过 30 集 = 废稿。**

## 一、 为什么本赛道是情绪流

| | 情绪流（本赛道） | 剧情流（不用本 skill） |
|---|---|---|
| 代表 | 婆媳、寻亲、养老、家产 | 悬疑、规则怪谈、强情节智斗 |
| 全剧锚点 | **情绪契约不变**：「让不认我的人当众认账」；矛盾按单元跑，一单元 20～30 集闭环后换矛盾不换情绪 | 信息阶梯推进，矛盾随真相转移 |
| 快节奏本质 | **情绪叠情绪**，不是事件叠事件 | 事件叠事件 |
| 观众动力 | 憋屈 → 期待释放 的循环加压；单元闭环前观众要的就是「这口气什么时候吐」 | 好奇 → 解谜 → 新谜 |
| 判定问句 | 「能不能一句话说清观众追的是哪种情绪？」能 → 情绪流 | 「观众追的是接下来发生什么？」→ 剧情流 |

**本 Skill 只做情绪流。** 混合剧允许主线情绪流 + 支线信息推进（如寻亲赛道里查档案），但主线必须走本文件的往返公式。

## 二、 情绪契约（立项第一句，全剧不换）

**通用写法：** 「让不认我的人当众认账」。

按赛道替换兑现物：

| 赛道 | 情绪契约（写到立项单上的一句话） |
|---|---|
| F1 婆媳清算 | 让把我当外人的一家人，当众认下我这十年的账 |
| F2 白眼狼子女 | 让嫌我老的儿女，当众认下我养他们大的账 |
| F3 寻亲认子 | 让抹掉我血缘的人，当众把我的孩子还给我 |
| F4 家产争夺 | 让当我死了的亲戚，当众把属于我的那份吐出来 |
| F5 养老困境 | 让推来推去的三个儿子，当众认下我的一张床位 |
| F6 保姆护工 | 让说我是外人的子女，当众认下这八年的情分 |
| F7 黄昏恋骗婚 | 让收割我孤独的人，当众把骗走的东西还回来 |
| F8 拆迁暴富与亲戚 | 让钱来了才活过来的亲戚，当众认下这声「一家人」不值钱 |

**契约三铁律：**
1. **一句话**，能写在立项单上，念给观众听不用解释；
2. **全剧不换**——你可以换矛盾、换对手、换战场，但这口气不能变味；
3. **每集都要续期**——每一集都得让观众感到「这口气还堵着」或「这口气吐了一点」，两者都不给的集 = 废集。

## 三、 证据烈度六档阶梯（施压方模板）

外界向主角执念砸的证据，按**可抵赖程度递减**分六档。任何赛道按序拉一遍即得 6 回合骨架。

| 档 | 证据类型（本赛道语境） | 可抵赖性 | 观众预期 |
|---|---|---|---|
| 1 | 道听途说 / 亲戚邻居传话（「你儿媳在外面说你…」） | 极高（「他们懂什么」） | 起步：执念合理 |
| 2 | 可抵赖的物证（旧物被动、门锁被换、银锁被扔） | 高（「东西在≠我干的」） | 微皱 |
| 3 | 看似铁证但有程序/外观漏洞（截图、代签的字条、剪过的录音） | 中（「这能证明什么」） | 着急 |
| 4 | 权威证据但程序可质疑（鉴定报告、律师函、过户手续、打码的监控） | 中低（「程序有问题，重来」） | 憋屈峰值 |
| 5 | 多重证据合围（人证+物证+记录+乡邻证言全吻合） | 低（「还没到那一步」） | 怒其不醒 |
| 6 | 不可推翻的专属铁证 + **主角亲历确证**（原始房契、临终录音、记账本、当年的收据） | 零 | 防线崩溃 / 闭环 |

**两条使用要点：**
- 第 6 档在**攻守转换之后**由主角打出，不是施压方打出——本赛道的爽点兑现物是「主角亮出底牌」，不是「反派证明自己错了」。
- 每档必须落到**具体物件**（记账本、房契、手环、工资条、护理日记）。写「证据升级」四个字 = 废回合。

## 四、 反驳成本六档阶梯（自证方模板）

主角每回合的反驳必须比上一回合**付出更多或冒更大风险**；反驳话术禁止复读。

| 档 | 反驳形态（本赛道语境） | 代价 |
|---|---|---|
| 1 | 口头否认（「我带孙子图什么」） | 零 |
| 2 | 质疑证据效力（「截图能证明什么」） | 零，但开始得罪亲人 |
| 3 | 翻旧账 / 找见证人（「当年谁在场，把老李叫来」） | 消耗人情 |
| 4 | 找组织（居委会、村委会、律师、公证处、派出所） | 社会成本，被说成「不顾一家人脸面」 |
| 5 | 赌上一切（当众立誓、押上名分/房产/这条命、当庭对质） | 不可逆风险 |
| 6 | 无牌可打 → 崩溃 或 最后一搏（以身入局、主动设局、反守为攻） | 剧情转折点 |

**增量铁律：** 第 N 回合的反驳必须含 **新信息 / 新行动 / 新代价** 至少其一；只重复第 N-1 回合话术的回合直接作废重写。

**本赛道专属提醒：** 主角的反驳不能用武力，只能用「理」和「证」。一旦主角动手打人，观众对他的同情立刻打折——把力气留给第 5 档的「赌上一切」。

## 五、 攻守转换（防疲劳阀）

一味挨打到第 4 回合观众就疲了。标准做法：

```text
被动反驳 ×3 回合 → 【转换：主角改变策略】假意认下 / 以身入局 / 主动设局
→ 反派误判得逞、变本加厉（施压方反成暴露方）
→ 主角收集反证 → 闭环反杀
```

- **单元 A（被动憋屈期）**：可以不大转换，但**代价必须见血**（卖房自证、当众下跪要说法、在门口等三个月），用自毁式执念加压；
- **全剧级攻守转换放在单元 B 开局**：A 单元反杀成功后，主角从「自证者」变「讨账者」，主动查向幕后——这一转换本身就是 A/B 接缝的引擎；
- **单元内小转换**：转换点 ≈ 该单元第 4 回合，且转换瞬间必须可断章。

## 六、 单元链（60～100 集的全剧骨架）

| | 单元 A | 单元 B | 单元 C（必要时 D） |
|---|---|---|---|
| 矛盾 | 执念 1（贴身的那件小事，如银锁） | 执念 2（更大的利益，如房本/拆迁款） | 执念 3（终极对手总清算 + 规矩本身） |
| 对手 | 前台反派（恶媳/恶婿） | 换层升级（既得利益子女 + 伪善亲戚） | 终极反派（拿走最大利益的人 / 偏心这条家规） |
| 闭环 | 当众认错一次（小尾） | 夺回实体利益（房、钱、赡养落实） | 彻底翻盘 + 情绪封顶 |
| 情绪 | 憋屈 → 吐气 | 憋屈 2.0（更亲更狠） | 大释放 |

**集数分配：60 集 = 2～3 单元；80 集 = 3 单元；100 集 = 3～4 单元。一单元 20～30 集（6 回合 × 3～5 集 + 闭环集）。**

**三缝合一规则（单元接缝处理，做不好 = 断追）：**
1. **旧单元残渣生出新矛盾**：A 闭环的爽点余温里必须埋 B 的火种（认错时当场暴露出更大的黑手、被吞掉的更贵的东西）；
2. **对手换层不换欲**：新对手是旧对手背后一层（恶媳 → 指使她的儿子 → 偏心这条家规），贪/势/面子同一种逻辑，烈度天然升档；
3. **主角弧光跟着单元走**：A 被动自证 → B 主动设局 → C 掌控规矩，每单元换一次打法。

**80 集标准示例：**

| | 单元 A（1～25） | 单元 B（26～52） | 单元 C（53～80） |
|---|---|---|---|
| 矛盾 | 银锁被扔、被诬偷首饰 | 老宅过户、拆迁款被代签 | 老伴遗嘱造假 + 全族清算 |
| 对手 | 儿媳（前台） | 儿子 + 姑姐（既得利益+舆论） | 堂亲 + 「嫁出去的女儿不算人」这条家规 |
| 闭环 | 账本当众念出，儿媳认错 | 房契摊开，份额要回 | 遗嘱作废，族亲当众认账 |

**长档（约 3 分钟/集）折算：** 集区间按「1 长档集 ≈ 2 标准集」折算，单元硬帽同步折半为 **10～15 长档集**（30 集 = 2～3 单元 / 40 集 = 3 单元 / 50 集 = 3～4 单元）；40 集示例——A 1～13 / B 14～27 / C 28～40。

## 七、 回合表输出格式（`/全剧大纲` 必产：每单元一张）

```text
【情绪契约】：让不认我的人当众认账 —— 具体兑现物=____
【单元 A】执念=____ ｜ 对手=____（第_层）｜ 闭环=____
  【回合 1】（第 1-4 集）：证据=档1 ____ ｜ 反驳=档1 ____ ｜ 回合尾断章：____
  【回合 2】（第 5-8 集）：证据=档2 ____ ｜ 反驳=档2 ____ ｜ 回合尾断章：____
  【回合 3】（第 9-12 集）：证据=档3 ____ ｜ 反驳=档3 ____ ｜ 回合尾断章：____
  【回合 4】（第13-16集）：证据=档4 ____ ｜ 反驳=档4 ____ ｜← 单元内攻守转换点
  【回合 5】（第17-20集）：证据=档5 ____ ｜ 反驳=档5 ____ ｜ 回合尾断章：____
  【回合 6】（第21-24集）：证据=档6 ____（施压方牌尽）｜ 反驳=档6 ____（主角亮铁证，反杀）
  【A 闭环 + 火种】（第 25 集）：兑现____ ｜ 但当场暴露 ____ → 单元B矛盾立项
【单元 B】执念=____ ｜ 对手=____（A 的对手背后一层）｜ 打法=主动设局
  …同构 6 回合，证据/反驳可从档 2 起步（主角已会战）
【单元 C】执念=____ ｜ 终极清算 ｜ 弧光封顶
```

**与付费墙挂线**（详见 `03-audience-paywall.md`）：
- 一级墙 ≈ 单元 A 内攻守小转换或首次亮底牌前；
- 二级墙 ≈ **A/B 单元接缝**（旧矛盾闭环当场暴露新矛盾、主角还没接招的那一瞬间）；
- 三级墙 ≈ 单元 C 开局前全剧最低谷（赢了每场、输了全局式的至暗）。

## 八、 回合表自检（写完逐条过）

```text
□ 每单元 6 回合上下，集数 ≤30（长档 ≤15）
□ 每回合证据档、反驳档都比上一回合升一档（两档都不升 = 废回合）
□ 每回合的反驳都带新增量（新信息/新行动/新代价），无复读
□ 第 4 回合附近有攻守转换，且转换瞬间可断章
□ 第 6 档铁证由主角打出，且是他立项时定下的「藏着的底牌」
□ 每单元闭环处都留了下一单元的火种
□ 全剧情绪契约一句话没变过
```
